# Level Zero — Brand Direction

## Name

**Level Zero**

The name represents the place before Level One: the stage where a game is imagined, designed, explored, prototyped, and made ready to exist.

## Preferred tagline

**Ideas to Play.**

Alternative brand line:

**Before Level One.**

## Logo direction

The chosen logo family is the **isometric foundation tile**.

The tile is deliberately simple. It can imply:
- the first tile of a level
- a foundation
- a blank building surface
- a modular world-building block
- the transition from nothing into something playable

## Primary mark

Use the **minimal blue isometric tile** when the identity should feel expressive, modern, and creative.

Best contexts:
- website/application launch
- marketing
- social profiles
- app icon
- presentations
- large brand moments

## Monochrome mark

Use the neutral/monochrome tile as the functional companion.

Best contexts:
- documentation
- print
- high-contrast environments
- watermarking
- understated UI
- situations where gradient color is inappropriate

These are variants of one brand system, not competing logos.

## Lockups

The identity should support:
- icon only
- horizontal icon + Level Zero
- stacked icon + Level Zero
- small-size simplified mark
- dark-background usage
- light-background usage

## Brand tone

The brand should feel:
- modern
- creative
- game-native
- serious enough for professional production
- not overtly retro/pixel-art
- not generic enterprise AI

The visual language of the product should remain primarily dark navy with electric blue accents.
