# Workbench SVG Icon Set

54 original SVG icons based on the icon language used in the Workbench mockups.

## Geometry
- ViewBox: 0 0 24 24
- Stroke: 1.8px
- Caps: round
- Joins: round
- Fill: none
- Color: `currentColor`

## Usage
```html
<img src="characters.svg" />
```

Or inline the SVG and control the icon with CSS `color`.

A symbol sprite is included as `workbench-icons-sprite.svg`.
